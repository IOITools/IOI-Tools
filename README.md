# 🧠 IOI TOOLS - Edición Universal

Bienvenido a **IOI Tools**, una suite ligera y portátil creada para mantener, optimizar y reparar sistemas Windows (10 y 11). 

Este no es solo un script más. Nació de la necesidad de tener el control total sobre mi propio sistema, sin instaladores, sin telemetría, sin IA integrada y con el 100% del código a la vista. Hoy, lo comparto contigo.

## ✨ Filosofía del Proyecto
- **100% Código Abierto:** Todo lo que ves es PowerShell puro. Puedes leerlo, modificarlo, mejorarlo o adaptarlo a tus necesidades.
- **Portable:** No requiere instalación. Descarga, ejecuta y listo.
- **Respetuoso:** No toca tus transparencias ni efectos visuales a menos que tú se lo pidas explícitamente. Nunca te robará datos ni te obligará a instalar nada.

## 🚀 ¿Cómo empezar?
1. Descarga todos los archivos y colócalos en una carpeta de tu confianza.
2. Ejecuta el archivo Run-IOI-GUI.bat (se solicitarán permisos de administrador de forma automática).
3. ¡Listo! Disfruta de la interfaz gráfica y de los módulos de optimización.

> **Nota técnica:** La interfaz está construida sobre WPF, por lo que funciona nativamente en Windows PowerShell 5.1 (incluido en Windows 10 y 11).

## 🛠️ ¿Qué puedes hacer con IOI Tools?
- **RAM:** Liberar memoria de forma segura.
- **Limpieza:** Eliminar archivos temporales, cache y registros.
- **Rendimiento:** Ajustar el plan de energía y prioridades.
- **Sistema:** Consultar información detallada en tiempo real.
- **Maestro:** Un motor de 13 fases para dejar tu Windows como nuevo (en una ventana separada).
